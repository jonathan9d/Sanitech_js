Aide & guide

Bienvenue dans le guide Sanitech. Suivez ces étapes pour maîtriser l'application.

1

Connexion

Connectez-vous avec vos identifiants. Mot de passe oublié ? Utilisez le lien dédié pour réinitialiser.

2

Ajouter des utilisateurs

Ouvrez l'onglet Utilisateurs, appuyez sur +, remplissez le formulaire puis enregistrez. Photo possible depuis la galerie.

3

Pointage

Bouton vert = entrée, bouton bleu = sortie. Chaque mouvement est tracé dans le Journal avec détection des retards.

4

Scanner QR

L'onglet Scanner lit les badges en direct via la caméra du téléphone ou l'ESP32-CAM (Wi-Fi SANITECH, mdp : 12345678).

5

Demandes d'absence

Créez une demande via le bouton + de l'onglet Demandes. Approuvez ou refusez ensuite.

6

Sécurité PIN

Activez un PIN à 4 chiffres dans Paramètres → Sécurité. L'app se verrouille après inactivité.

7

Automatisations

Sortie automatique à heure fixe, archivage des inactifs, résumé quotidien : tout se règle dans Paramètres.

8

Sauvegarde & navigation

Exportez vos données en JSON, CSV ou PDF. Glissez entre les onglets, tirez vers le bas pour actualiser.

help_outline Problèmes fréquents

Vérifiez les permissions caméra dans les paramètres de votre téléphone. Essayez de changer la caméra dans le menu déroulant.
Connectez-vous au Wi-Fi SANITECH (mot de passe 12345678), puis attendez 10 secondes avant de scanner.
Tirez vers le bas pour actualiser. Vérifiez que la base SQLite est bien initialisée dans À propos.
